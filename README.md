# AquaSuporte(Prototipo)

O projeto foca em ajudar aquaristas a pesquisar e entender de forma mais rapido coisas basicas do aquarismo, alem de ajudar nos calculos de forma mais intuitiva. Mas isso e só um teste, na pratica a loja não funciona mas e um prototipo.

## Funcionalidades

- Calculo de volume do aquário, de quantidade de substrato e da vazão necessária no aquario
- Catalogo fácil de entender sobre cada peixe
- Guias para aprendizados
- E uma loja(não funcional)

## Instalação

prepare uma pasta para receber o projeto
abra o git CMD e coloque esses comandos:
cd caminho-para-o-seu-repositorio
git clone https://github.com/fabianodacunha/Projeto-AquaSuporte.git
Pronto o projeto já esta na sua maquina agora
